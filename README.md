📚 Latihan Interaktif Tahun 4 (SK)
Koleksi latihan interaktif dalam format HTML untuk murid Tahun 4 Sekolah Kebangsaan (SK) di Malaysia. Setiap latihan dibina daripada bahan soalan yang disediakan, supaya murid boleh belajar langkah demi langkah.
---
🎯 Prinsip Pembelajaran
Belajar → Cuba → Petunjuk → Semak → Baiki → Maju
---
✅ Peraturan Latihan
Peraturan	Keterangan
💡 Petunjuk	1 petunjuk sahaja untuk setiap soalan
🔁 Cuba semula	Tiada. Jawapan salah terus ke soalan seterusnya
💯 Markah	Jumlah 100%, diagihkan kepada setiap soalan
📄 Fail	1 subjek = 1 fail HTML yang berdiri sendiri
---
🎨 Reka Bentuk
Font besar dan mudah dibaca oleh murid Tahun 4
Gaya visual ceria dan child-friendly
Animasi untuk jawapan betul dan jawapan salah
Teks ringkas, tiada ayat panjang
---
📁 Struktur Repository
```
/
├── README.md
├── <subjek-1>.html
├── <subjek-2>.html
└── ...
```
> Setiap fail HTML tidak bergantung pada fail lain. Boleh dibuka terus dalam pelayar web.
---
🚀 Cara Guna
Buka secara lokal
Muat turun atau clone repository ini.
Klik dua kali pada mana-mana fail `.html`.
Terbitkan dengan GitHub Pages
Pergi ke Settings → Pages dalam repository.
Di bawah Build and deployment, pilih Deploy from a branch.
Pilih branch `main` dan folder `/ (root)`, kemudian Save.
Pautan setiap latihan akan jadi:
```
   https://<username>.github.io/<nama-repo>/<subjek>.html
   ```
Pautkan dari website
Gunakan `target="_blank"` supaya latihan dibuka dalam tab baharu:
```html
<a href="https://<username>.github.io/<nama-repo>/<subjek>.html" target="_blank" rel="noopener">
  Mula Latihan
</a>
```
---
➕ Tambah Latihan Baharu
Sediakan bahan soalan subjek (PDF atau fail lain).
Tukar bahan menjadi 1 fail HTML mengikut peraturan di atas.
Namakan fail mengikut subjek (contoh: `<subjek>.html`).
Upload ke repository dan commit.
Tambah pautan baharu dalam website.
